07 · Method and honesty

What this map is, and what it is not.

Source. EU Transaction Log public data download, extract of —, verified emissions 2005-2025. Installations are joined on registry code plus installation identifier; the bare identifier repeats across countries. A reported value of −1 means "not reported" and is treated as missing, never as zero.

Owner of record is the ETS account holder, usually the operating subsidiary, not the ultimate parent. Resolving ownership is a separate problem (GEODEP's company-resolution track) and is deliberately not attempted here.

One error, kept. GB_918, an INEOS CHP plant in Cleveland, is geocoded to Cleveland, Ohio. It stays on the map because it is exactly the kind of mistake a map catches and a table never does.

GEODEP · ETS map is a sandbox built alongside the GEODEP project (industrial installations, emissions, ownership and transition plans). It reads two public files and is not part of the GEODEP methodology.

Data: European Commission, EU Transaction Log public data download. Emissions are verified tonnes of CO2-equivalent as reported to the registry. Sector groups follow ETS activity codes. MIT-licensed code; data files retain their public-data terms.
