Method and data

Source. EU Transaction Log public data download, extract of —, verified emissions 2005-2025. Installations are joined on registry code plus identifier. A value of −1 means "not reported" and is treated as missing, never as zero.

Baseline. Change is 2025 against each installation's mean over 2021-2023. Closure is counted only when the ETS permit is revoked. Operator is the ETS account holder, usually a subsidiary, not the group parent.

One error, kept. GB_918 (INEOS CHP, Cleveland UK) is geocoded to Cleveland, Ohio: the kind of mistake a map catches. Code, SQL and data: github.com/Yusnelkis/geodep-ets-map. Basemap © CARTO © OpenStreetMap.
